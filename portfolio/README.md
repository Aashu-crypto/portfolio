# Aashutosh Gandotra - Portfolio Website

A modern, responsive portfolio website showcasing my experience as a Full-Stack Mobile Developer with 3+ years of experience specializing in React Native, React, and Node.js.

## 🚀 Features

### Core Sections

- **Hero Section**: Professional introduction with contact links
- **Skills**: Comprehensive technology stack display
- **Experience**: Detailed work history with achievements
- **Education**: Academic background
- **Certifications**: Professional certifications from Meta, 100xDev, and Udemy
- **Projects**: Showcase of key projects including All Cures and Igris
- **GitHub Stats**: Dynamic GitHub contribution display
- **LeetCode Stats**: Coding problem-solving statistics
- **Contact Form**: Direct communication interface

### Technical Features

- **SEO Optimized**: Meta tags, Open Graph, Twitter Cards, structured data
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Performance Optimized**: Next.js 16 with optimized assets and static rendering
- **Resume API**: JSON endpoint for resume data (`/api/resume`)
- **Sitemap & Robots.txt**: Automated SEO files
- **Accessibility**: ARIA labels and semantic HTML

## 🛠️ Tech Stack

- **Frontend**: React, Next.js 14, TypeScript, Tailwind CSS
- **Icons**: React Icons (Font Awesome, Simple Icons)
- **Animations**: CSS transitions and hover effects
- **Forms**: Formspree integration
- **SEO**: Next.js metadata API, structured data
- **Deployment**: Vercel/Netlify ready
